        Frequently Asked Questions
      


      

        

          
What does sub_confirmation=1 do?

          

            It is an official YouTube query parameter. When users open your channel URL with this flag on a desktop or mobile browser, YouTube renders an immediate confirmation popup: "Confirm Channel Subscription: Are you sure you want to subscribe to [Channel]?"
          

        


        

          
Does it violate YouTube Terms of Service?

          

            No! It is a built-in feature supported directly by YouTube. It never forces a silent background subscription (the user still intentionally clicks "Subscribe"), so it remains 100% compliant.
          

        


        

          
Can I link directly to a specific video?

          

            The subscription parameter works specifically for channel URLs (`/@handle`, `/channel/ID`, or `/c/name`). It does not open a subscription modal on standard `watch?v=` links.
          

        


        

          
What happens on mobile phones?

          

            If the user has the YouTube app installed, the deep link opens your channel page directly with the red subscribe button front-and-center. On mobile browsers, it opens the confirmation dialog.
